# Nihongo PL

Kurs japońskiego po polsku, od pierwszego znaku do egzaminu JLPT N5.

## Uruchomienie

```bash
npm install
npm run dev
```

Strona działa pod adresem http://localhost:3000.

## Testy

```bash
npm test          # testy jednostkowe (Vitest)
npm run test:e2e  # testy w przeglądarce (Playwright)
```
